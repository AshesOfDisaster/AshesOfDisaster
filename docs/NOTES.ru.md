# Ashes of Disaster — хост-мод для Among Us

## Запуск
1. Нужны: BepInEx 6 IL2CPP в папке Among Us (игру один раз запустить), Python 3, .NET SDK 8 (скрипт сам попробует поставить через winget).
2. Двойной клик по `Run all.bat` (или `python run_all.py`) — скрипт найдёт игру, соберёт мод и положит `AshesOfDisaster.dll` в `BepInEx/plugins`.
3. Если в plugins лежат AmongUsStable / AUnlocker — на время тестов убери.
4. Если сборка упала — скрипт сохранит `build_errors.txt` (только ошибки) и `build_log.txt` (полный лог).

## Что есть
- Настройки с вкладками (в меню настроек лобби рядом с «Настройки игры» и «Роли»): Лобби, Защита, Игра, Мирные, Предатели, Нейтралы, Другое. Размеры вкладок подгоняются в `BepInEx/config` (секция Layout). Новая настройка = 1 строка в `src/Options.cs` + перевод в `Translator.cs`.
- Роли: Крестьянин, Облако, Строитель, Маляр, Паук, Виджилант (`src/RoleLogic.cs`). **Шанс появления у всех ролей по умолчанию 0** — включи нужные в меню настроек (вкладки Мирные / Предатели / Нейтралы).
- Способности запускаются **питомцем**: игрок гладит питомца (у игрока должен быть надет питомец). Роли без активной способности (Крестьянин, Строитель, Маляр) работают сами.
- Старт с любого числа игроков, автозапуск, `/cancel`.
- Команды работают и у игроков без мода: `/h /r /m /id /lang /v /now /t /color`; для хоста ещё `/o /kick /ban /unban /say /start /cancel /end /kill /ab /who /role /dump`.
- Защита: бан-лист по friend code, запрещённые ники, кик по уровню, кик без friend code (файлы в `BepInEx/config/AshesOfDisaster/`).
- Русский/английский по языку игры.
- Создатели (niko & Акакиш) в главном меню.

## Как проверить роли
- `/who` (хост) — кто какую роль получил; `/role ID роль` — выдать роль для теста; `/ab` — способность без питомца (работает там, где открыт чат).
- В `BepInEx/LogOutput.log` ищи строки `Harmony: patch classes ok=..., failed=...`, `Pet hook ...`, `Ability trigger ...`, `Roles assigned ...` — по ним видно, что установилось и дошло ли погладивание питомца до мода.

## Статус над ником и роль выброшенного
- Статус над ником (роль, «до щита: 2 задания», «паутин 1/3» ...): у хоста рисуется всегда, для остальных игроков — экспериментальная настройка «Статус над ником» (по умолчанию ВЫКЛ, вкладка «Игра»). Мод шлёт им личный SetName напрямую одному клиенту (; прежняя схема с перехватом не работала и в аварийной ветке рассылала ник всем — это и кикало). Раньше на старте игры хоста кикало, причина не установлена — если кикнет, выключи настройку и пришли строки `NameInfo:` и `Disconnect via` из лога.
- Когда игрока выбрасывают на собрании, в чат пишется его роль (настройка «Писать роль выброшенного игрока»).

## Заметки
- Сообщения игрокам идут через чат, а он в раунде закрыт (иначе сервер кикает за «Hacking»). Поэтому секретные сообщения роли (штраф, «в паутине» и т. п.) копятся и приходят на ближайшем собрании; хосту всё показывается всплывашкой сразу.
- Если какого-то метода нет в твоей версии игры, патч пропускается и пишется в лог — остальной мод продолжает работать.
- Если хоста выкидывает при способности: в `BepInEx/LogOutput.log` смотри последние строки перед `Disconnect via` / `KickPlayer`: `RPC MurderPlayer ...` (убийство) или `RPC SnapTo ...` (паутина держит жертву).
- Виджилант (не предатель): убийство шлётся от имени живого предателя (сервер кикает за убийство от не-предателя). Если живых предателей нет — убийство пропускается (`Kill skipped` в логе). Неудачное убийство (сработал щит) в сеть не шлётся.
- Строитель: питомец закрывает ближайшую дверь (обычное закрытие дверей игры, откроется само). Работает только у дверей; задержка — `BuilderCooldown`.
- Облако (нейтрал): питомец оставляет невидимое облако (лимит `CloudMax`); когда кто-то наступает, облако исчезает, а владельцу приходит «паника»: у него мигает экран как при саботаже реактора (адресный RPC UpdateSystem,; остальные ничего не видят), хосту — всплывашка, остальным плюс сообщение на собрании. Облака пропадают на собрании. Если кикает после наступания на облако — смотри строки `RPC UpdateSystem (panic flash)` и `Disconnect via` в логе.
- Облако: с шансом `CloudStormChance` (по умолчанию 10%) облако оказывается грозой — наступивший погибает (убийство через self-kill жертвы — работает и без живых предателей). Защита Крестьянина отменяет грозу. Метка: гроза видна только владельцу (сообщение при постановке: хосту сразу, остальным на собрании + счётчик «гроз» над ником/в /m). Показать грозу всем игрокам без мода нельзя (нужен сетевой объект, сервер его кикает).
